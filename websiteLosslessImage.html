Core Concept

What makes it lossless?

Unlike lossy compression (used in JPEG), lossless compression guarantees a pixel-perfect reconstruction of the original image. The key is exploiting redundancy — repeating patterns that don't need to be stored twice.

🔍
Redundancy Elimination
Images contain vast spatial redundancy — neighboring pixels tend to be similar. Compression algorithms find and remove this repetition without discarding information.
📐
Perfect Fidelity
Every single bit of the original image is recoverable after decompression. The decoded file is mathematically identical to the source — bit for bit.
⚡
Two Core Approaches
Bit-plane transformation encodes binary layers efficiently. Predictive coding stores prediction errors rather than raw values — both exploit pixel correlation differently.
📊
Entropy Coding
A final stage uses Huffman or Arithmetic coding to assign shorter binary codes to frequently occurring values — squeezing every last bit of redundancy out.
Technique 01

Bit-Plane Transformation

An 8-bit pixel value (0–255) is broken into 8 separate binary layers. Each layer contains just one bit per pixel. Smooth image regions produce long runs of identical bits — perfect for compression.

💡 Why it matters
The most significant bits (planes 7–5) carry the main structure of the image. The least significant bits (planes 0–2) contain fine details and appear almost random — these are harder to compress.

8 Bit-Planes

Run-Length Coding (RLC) on Bit-Planes

Smooth regions in an image produce long runs of the same bit (0 or 0 or 0 or 1 or 1 or 1...). RLC stores the count instead of each individual bit, dramatically reducing data.

Technique 02

Lossless Predictive Coding

Instead of storing raw pixel values, the encoder makes a prediction from neighboring pixels and only stores the error. Since neighbors are usually similar, errors are small — and small numbers compress far better.

Pixel neighborhood (5×5 excerpt)
Known neighbors   Target pixel
JPEG-LS / LOCO-I Median Edge Detector
The MED predictor tests for horizontal or vertical edges:
if C ≤ min(A,B): predict = max(A,B)
if C ≥ max(A,B): predict = min(A,B)
else: predict = A + B - C
Prediction Formula
P̂ = f(A, B, C)
error = X − P̂
A = left neighbor   B = top neighbor   C = top-left   X = current pixel

Technique 03

Entropy Coding

Once spatial redundancy is removed, entropy coding assigns shorter binary codes to more frequent symbols. This is the final compression stage used in virtually all lossless formats.

Huffman Code Table
Frequent prediction errors (near zero) get shorter codes. Rare values get longer codes. On average, this beats fixed-length encoding.
Arithmetic Coding
Arithmetic coding represents the entire message as a single fraction in [0,1). It can achieve the theoretical entropy limit and is used in JPEG-LS, HEIF, and WebP.
Number line subdivision
Each symbol subdivides the interval according to its probability. The final interval encodes the entire sequence.
💡 Practical comparison
Huffman: ~0.05 bits above entropy limit. Fast, widely supported (PNG, DEFLATE).
Arithmetic: reaches theoretical entropy limit. Used when maximum compression matters.
Real-World Use

Why Lossless Matters

In fields where every pixel carries critical information, lossy compression is simply not an option. Here's where lossless compression makes an irreplaceable difference.

🏥
Medical Imaging
MRI, CT, and Ultrasound scans must be stored and transmitted without any data loss. A misread lesion caused by compression artifacts could mean a misdiagnosis. DICOM uses lossless codecs exclusively for diagnostic images.
DICOM · JPEG-LS
🔬
Scientific Data
Satellite imagery, astronomical photography, and microscopy generate terabytes of precision data. Any lossy artifact would corrupt scientific measurements — lossless is mandatory.
FITS · PNG · TIFF
🗄️
Digital Archiving
Libraries and museums digitize rare documents and artworks for permanent preservation. Only lossless formats guarantee the archive will be identical to the original in 100 years.
TIFF · PNG · WebP-L
🌐
Web & Bandwidth
PNG and WebP (lossless mode) reduce bandwidth for UI graphics, icons, and screenshots — transparent backgrounds, crisp text, and pixel-perfect logos all require lossless encoding.
PNG · WebP · AVIF
🎞️
Professional Video
Cinema RAW and professional editing workflows use lossless video (ProRes 4444, Apple ProRes RAW) to preserve maximum quality through color grading and compositing pipelines.
ProRes · REDCODE
🧠
ROI Coding (Medical)
Region-of-Interest compression isolates the clinically relevant portion of an image for maximal lossless fidelity, while applying higher compression elsewhere — balancing diagnostic integrity with storage efficiency.
JPEG 2000 · ROI

Choosing the Right Algorithm

Each lossless format makes different trade-offs between compression ratio, speed, and complexity. There is no single winner — context decides.

The AI Frontier

Treating Pixels as Language

The newest frontier in lossless compression uses Large Language Models to predict pixel values — treating an image as a sequence of "visual tokens," just like words in a sentence.

P-LLM: Language Models for Pixel Prediction
Traditional codecs predict the next pixel using a few neighbors. A large language model can attend to the entire image context — recognizing objects, textures, and semantic patterns across thousands of pixels to make a far more accurate prediction. A more accurate prediction means a smaller error — which means fewer bits.

This is the same principle that makes LLMs excel at next-token prediction in text: understanding context at scale. Applied to images, it pushes compression ratios beyond what any classical algorithm can achieve.
Pixel sequence as "language tokens"
Each pixel value is a "token." The LLM predicts the next token using the full prior context — like predicting the next word in a sentence.
🤖
Context Window = Entire Image
Unlike classical predictors that see 2–4 neighbors, an LLM sees the whole image. It recognizes that a sky region will be blue, a face will have skin tones — using semantic understanding.
📉
Smaller Errors = Better Compression
Better prediction → smaller errors → more peaked error histogram → lower entropy → fewer bits required. AI achieves this systematically across all image types.
⚖️
Speed vs Ratio Trade-off
P-LLM requires GPU inference for each pixel — far too slow for real-time use. Classical JPEG-LS remains king for speed-critical applications like medical device streaming.
Key Takeaways

The Full Picture

Lossless compression is a layered process — each stage removes a different type of redundancy.

1
Bit-Plane Decomposition — splits a pixel into binary layers; smooth regions produce compressible runs of identical bits via RLC.
2
Predictive Coding — stores only the prediction error instead of raw pixel values, dramatically reducing data entropy.
3
Entropy Coding — Huffman or Arithmetic coding assigns optimal bit lengths to each symbol, squeezing to the information-theoretic limit.
4
AI Frontier — LLM-based predictors use semantic context to outperform classical algorithms, at the cost of speed.
